# Water Quality Monitoring System (2024–2025)

A real-time embedded system developed using Arduino Nano to monitor water quality using:

- pH Sensor
- TDS Sensor
- Turbidity Sensor
- Temperature Sensor

## Features
- Real-time sensor monitoring
- LCD display output
- Calibration of sensors
- Embedded C programming
- Data processing and system integration

## Hardware Used
- Arduino Nano
- pH sensor module
- TDS sensor module
- Turbidity sensor
- LM35/DS18B20 temperature sensor
- 16x2 LCD display

## Software Tools
- Arduino IDE
- Proteus (Simulation)
- VS Code

## Skills Demonstrated
- Sensor interfacing
- Embedded C programming
- Analog-to-Digital Conversion
- Signal processing
- System debugging and testing
- Circuit design and simulation
